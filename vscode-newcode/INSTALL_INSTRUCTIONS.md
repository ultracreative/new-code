To install the 'New Code' language extension in VS Code:

1.  Open VS Code.
2.  Go to the Extensions view by clicking on the square icon on the sidebar or pressing `Ctrl+Shift+X` (Windows/Linux) or `Cmd+Shift+X` (macOS).
3.  Click on the three dots (...) in the top-right corner of the Extensions view header.
4.  Select "Install from VSIX...".
5.  Navigate to the following path and select the `.vsix` file:
    `/Users/danrodriguez/Desktop/new-code/vscode-newcode/vscode-newcode-0.1.0.vsix`
6.  Click "Install".
7.  After installation, you might need to reload VS Code for the extension to take full effect.

Once installed, files with the `.nc` extension should be recognized as "New Code" files, and you should get syntax highlighting and potentially other language features if the language server is configured and running.
